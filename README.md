This is a simple site to practice password verification. You must login to make a post. Only "members" can see usernames and times posted and only admins can delete messages.
To become a member you must enter the correct passowrd on the become member page.
Seeing as this was mainly practice about passwords, I did not spend much time on making the site look good. I didn't even change from the basic font.

The logo was made by CHATgpt and edited by Claude.

.env looks like:
CONNECTION_STRING = "STRINGHERE"
NODE_ENV = "development"
SESSION_PASSWORD = "password"
MEMBERSHIP_PASSWORD = "member"
